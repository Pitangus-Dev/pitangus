# Button

Botones: amarillo sólido para hacer lo principal, contorno o fantasma para el resto.

- **primary** (`sulphur` + `on-sulphur`): «Nuevo análisis» en la cabecera, la acción principal de un formulario o diálogo, la llamada de un estado vacío. Como mucho uno por zona.
- **outline** (`surface` + `line-strong`): acciones secundarias.
- **ghost**: acciones terciarias y de fila.
- **danger** (`critical` sobre `surface`): eliminar, desconectar; la confirmación vive en un diálogo.

Altura 32px, `radius-md`, texto en verbo («Añadir dominio»). Icono Phosphor del mapa del manual solo si ayuda a reconocerla (`Scan` para analizar, nunca «reproducir»). Nunca «→» al final. Sin amarillos pálidos ni botones negros.
